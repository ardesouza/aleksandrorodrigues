PROJETO 01 · CONSULTAS COMPLEXAS

Cruzamento de dados acadêmicos e financeiros

Consulta desenvolvida para relacionar informações acadêmicas e financeiras, permitindo analisar diferentes situações a partir do relacionamento entre múltiplas tabelas.

O exemplo demonstra a utilização de relacionamentos entre dados, filtros e regras de negócio para transformar informações distribuídas no banco de dados em um resultado consolidado.

SQL Server JOIN Filtros Regras de negócio
Consulta SQL 
SELECT
    A.RA,
    A.NOME AS ALUNO,
    C.NOME AS CURSO,
    P.CODPERLET AS PERIODO_LETIVO,
    F.STATUS AS SITUACAO_FINANCEIRA
FROM ALUNOS A
INNER JOIN MATRICULAS M
    ON M.RA = A.RA
INNER JOIN CURSOS C
    ON C.CODCURSO = M.CODCURSO
INNER JOIN PERIODOS P
    ON P.ID = M.IDPERIODO
LEFT JOIN ( 
    SELECT DISTINCT
        RA,
        STATUS
    FROM FINANCEIRO
) AS F
    ON F.RA = A.RA
WHERE M.STATUS = 'ATIVO'
ORDER BY A.RA;
Resultado da consulta
RA ALUNO CURSO PERIODO_LETIVO SITUAÇÃO_FINANCEIRA
100001 João Silva Administração 2026/3 Regular
100002 Maria Souza Pedagogia 2026/3 Pendente
100003 Ana Oliveira Sistemas de Informação 2026/3 Regular
O que este exemplo demonstra?

O relacionamento entre diferentes conjuntos de dados permite consolidar informações acadêmicas e financeiras em uma única consulta, facilitando a análise e a identificação de situações específicas.

PROJETO 02 · REGRAS DE NEGÓCIO

Identificação de situações por regras de negócio

Consulta desenvolvida para identificar registros que atendem a diferentes condições de negócio, utilizando filtros, operadores condicionais e classificação dos resultados.

O exemplo demonstra como regras definidas para um determinado processo podem ser representadas diretamente na consulta SQL, facilitando a identificação e análise de situações específicas.

SQL Server CASE WHERE Regras de negócio
Consulta SQL 
SELECT
    A.RA,
    A.NOME AS ALUNO,
    F.VENCIDOS,
    CASE
        WHEN F.VENCIDOS > 0
            THEN 'PENDÊNCIA FINANCEIRA'
        WHEN M.STATUS = 'ATIVO'
            THEN 'REGULAR'
        ELSE 'VERIFICAR'
    END AS SITUACAO
FROM ALUNOS A
INNER JOIN MATRICULAS M
    ON M.RA = A.RA
LEFT JOIN FINANCEIRO F
    ON F.RA = A.RA
WHERE M.STATUS IN ('ATIVO', 'PENDENTE')
ORDER BY RA;
Resultado da consulta
RA ALUNO VENCIDOS SITUACAO
100001 João Silva 0 REGULAR
100002 Maria Souza 2 PENDÊNCIA FINANCEIRA
100003 Ana Oliveira 0 REGULAR
O que este exemplo demonstra?

A utilização de estruturas condicionais permite transformar diferentes informações do banco de dados em uma classificação objetiva, seguindo regras previamente definidas para o processo.

PROJETO 03 · TRATAMENTO E CONSOLIDAÇÃO

Consolidação de informações para análise

Consulta desenvolvida para consolidar informações distribuídas em diferentes registros e apresentar os dados de forma organizada para análise.

O exemplo utiliza uma CTE para organizar os dados antes da consulta final, permitindo aplicar agrupamentos e funções de agregação para obter indicadores consolidados.

SQL Server CTE GROUP BY Agregação
Consulta SQL 
WITH RESUMO AS (

    SELECT
        C.NOME AS CURSO,
        COUNT(A.RA) AS TOTAL_ALUNOS
    FROM ALUNOS A

    INNER JOIN MATRICULAS M
        ON M.RA = A.RA

    INNER JOIN CURSOS C
        ON C.CODCURSO = M.CODCURSO

    WHERE M.STATUS = 'ATIVO'

    GROUP BY C.NOME

)

SELECT
    CURSO,
    TOTAL_ALUNOS
FROM RESUMO
ORDER BY TOTAL_ALUNOS DESC;
Resultado da consulta
CURSO TOTAL_ALUNOS
Administração 428
Pedagogia 356
Sistemas de Informação 284
Ciências Contábeis 217
O que este exemplo demonstra?

A consolidação de dados permite transformar grandes volumes de registros em informações resumidas, facilitando a geração de relatórios e a análise de indicadores.
